# Classificador de Gestos com a Mão

## Sobre o projeto

Este projeto utiliza Inteligência Artificial para classificar
gestos realizados com a mão através da câmera.

O modelo foi desenvolvido utilizando o Google Teachable Machine.

## Classes

O modelo possui três classes:

- Palma
- Punho
- Polegar

## Origem dos dados

Os dados foram coletados por mim utilizando a webcam,
diretamente no Teachable Machine.

Foram coletados aproximadamente 50 exemplos para cada classe.

## Treinamento

O modelo foi treinado utilizando o Google Teachable Machine
como um projeto de classificação de imagens.

## Reflexão

Durante os testes, o modelo apresentou alguns erros em
determinadas situações. Isso pode ter acontecido devido
à iluminação, posição da mão, distância da câmera ou
semelhanças entre alguns exemplos utilizados no treinamento.
Acredito que aumentar a variedade dos dados poderia
melhorar o desempenho do modelo.
